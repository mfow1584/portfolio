# portfolio
This is a collection of files meant to demonstrate conceptual understanding of software interactions across a set of languages and frameworks (Spring, Java, C#, Python).

The Python section contains two sets of files that highlight different skills. The first is a pair of scripts to show an understanding of how one can interact with an API and process the information retrieved by a given request. The second is a set of class files used in a school project to show familiarity with object-oriented principles and how different classes can interact.

The C# section contains a class file that outlines interactions with a provided spreadsheet file. The goal was to highlight basic value retrieval from a file and then internal processing within the class.

The Spring/Java section contains school project files for a Spring Boot application to demonstrate an understanding of how requests made on a web application are translated into specific operations on a database. We were responsible for editing a set of Java files to ensure that the information required to complete a given request can be retrieved from a database through table mapping, and by outlining internal operations within the application triggered through REST mapping.
